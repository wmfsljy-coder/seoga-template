# 학교 서가 — 한 권 읽고, 한 줄 남기기

학교 도서관 독서 프로그램 웹앱입니다. **구글 시트 한 장 + Apps Script** 로 돌아가서 서버도, 구축비도 들지 않습니다.
경남 웅천고등학교에서 2026년 2학기에 운영 중인 '웅천 서가'를 다른 학교가 그대로 쓸 수 있게 학교 전용 값을 빼고 정리한 판입니다.

- **시연본(설치 없이 둘러보기)**: https://wmfsljy-coder.github.io/seoga-template/
- **설치 안내**: [설치안내.md](설치안내.md) — 처음 설치 20분, 그 뒤 담당 업무 주 2분

## 무엇을 하나

| 학생 | 선생님·도서부 |
| --- | --- |
| 이달 추천 도서(학교 장서에서 매달 자동 선정)·도서 검색·권장도서·작가 이야기 | 새 글 점검(겹침 자동 비교·금칙어), 글 내리기 |
| **단계형 글쓰기** — 라벨(한 줄 소개 40~90자) → 문장(책 속 한 문장) → 독후감(300~700자) | ‘선생님 라벨’로 추천 한 줄, 도장 주기 |
| 게시판(이름 없이 학급만 표시)·부문별 투표 | 북퀴즈 다음 주 미리 보기·문제 바꾸기 |
| 북퀴즈 풀기·문제 내기(다음 주 퀴즈 책으로) | 참여 현황·독서 기록(생활기록부 독서활동상황 형식 내려받기) |
| 내 서재 — 도장판·별·책갈피 | 도서부: 금요일 상품권 배부·무르기·배부 기록 |

**보상 구조** — 한 주 도장 5칸(종류마다 상한: 라벨·문장 각 1, 독후감 2, 퀴즈 2), 넘긴 활동은 책갈피(5장 = 만능 도장), 도장 5개 = 별 1개, 별 1개 = 문화상품권 1매(설정에서 바꿈).
이벤트 다섯 가지(도장 배수·추첨·반 대항·미션·무지개 별), 학급 전원 가입 만능 도장, 월말 부문별 시상.

**자동으로 하는 일** — 독서로(read365) 공개 조회로 장서·표지·청구기호·대출 가능 여부를 하루 세 번 받아 오고, 매달 추천 도서를 뽑고, 매주 북퀴즈를 한 주 앞서 정하고, 주 1회 시트를 드라이브에 백업합니다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `core.gs` | 모든 규칙과 계산(시트·브라우저와 무관한 순수 로직) |
| `Code.gs` | 구글 시트·메일·드라이브·트리거를 붙이는 부분 |
| `index.html` | 화면 전체(학생·교사·관리자·도서부) |
| `appsscript.json` | 매니페스트(서울 시간대, 웹앱 설정) |
| `tools/` | 시연본 만들기(`build_demo.py`), 자동 시험(`tests/`) |

## 시험

```bash
for f in tools/tests/*.js; do node "$f"; done     # 시험 50여 개(시나리오별)
python tools/build_demo.py                        # demo.html — 브라우저로 바로 열리는 시연본
```

## 개인정보

학생 글·명단은 **설치한 학교의 구글 시트에만** 저장되고 다른 곳으로 보내지 않습니다(AI 서비스 사용 없음). 게시판에는 이름 없이 학급만 보이고, 투표는 누가 했는지 남기지 않습니다.
학생은 처음 들어올 때 개인정보 수집·이용 안내를 읽고 동의해야 참여할 수 있으며, 보유 기간·담당자는 설정 시트에서 학교 사정에 맞게 고칩니다.
